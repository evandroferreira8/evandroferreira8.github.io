# Evandro Ferreira — site pessoal V7

Versão V7 com a direção visual consolidada:

- abertura retomando a atmosfera escura da primeira proposta;
- lua/astro integrado ao céu e curvas inspiradas em dunas;
- cabeçalho transparente no topo e refinado ao rolar;
- galeria em mosaico/masonry preservando a proporção original das fotografias;
- lightbox para ampliar as imagens;
- retrato e seção “Um pouco de mim” mantidos;
- Morro do Careca exibido inteiro, sem corte forçado, e também ampliável;
- arquivo de matérias com filtros e links públicos.

## Publicação

Envie `index.html`, `styles.css`, `script.js` e a pasta `assets` para o mesmo diretório no GitHub Pages.
